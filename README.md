# Calculadora Simples

Calculadora de terminal feita em Python. O programa pede dois números e uma operação, e mostra o resultado.

## Operações disponíveis

| Símbolo | Operação      |
|---------|---------------|
| `+`     | Adição        |
| `-`     | Subtração     |
| `*`     | Multiplicação |
| `/`     | Divisão       |

## Como usar

1. Tenha o Python 3 instalado.
2. Execute no terminal:

   ```bash
   python calculadora.py
   ```

3. Digite o primeiro valor, o segundo valor e a operação desejada.

## Exemplo de execução

